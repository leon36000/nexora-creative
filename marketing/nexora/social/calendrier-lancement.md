# Calendrier éditorial de lancement : 30 jours

Aucune date n’est inscrite : le jour 1 est le jour du lancement, fixé par le fondateur. Quatre piliers en rotation : **rêve**, **outil**, **Québec**, **coulisses**. Chaque jour : un texte fr-CA et un texte en-CA courts (aucun chiffre, prix, date ni client inventé ; l’état de chaque outil est celui de `web/src/i18n/apps.ts`), une image du dossier `social/final/`, des mots-clics courants (aucune marque tierce) et le **texte alternatif** de l’image dans les deux langues. Les chemins d’image portent `{l}` : remplacer par `fr` ou `en`.

Appel à l’action : « Planifier un diagnostic » (accompagnement sur mesure, réel), « Voir les solutions », « Rejoindre la liste d’attente » (outils non livrés). « Essayer Nexora Creative » n’est pas utilisé : Nexora Creative est à une étape ultérieure, rien n’est livré.

Consignes d’accessibilité : coller le texte alternatif dans le champ prévu de chaque plateforme (pas seulement dans la légende) ; mots-clics en casse mixte (#IntelligenceArtificielle) pour les lecteurs d’écran ; mots-clics à la fin du texte ; pas d’émoji comme puce ; pour les PDF et carrousels, répéter l’essentiel dans la légende.
