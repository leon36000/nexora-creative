# Nexora Creative

Studio créatif IA de Nexora AI (vidéo, image, audio), application web de l'environnement de travail du panneau « Mes outils ». État : **conception** ; aucun code de produit n'est encore dans ce dépôt.

- [`ARCHITECTURE-NEXORA-CREATIVE.md`](ARCHITECTURE-NEXORA-CREATIVE.md) : architecture cible conditionnelle, risques de licence, lots de développement.
- [`recherche/`](recherche/) : études des bases open source, du montage, des modèles et licences (MiniMax H3), de l'inférence et de la sécurité, de l'AI Director et du registre de capacités, d'OpenField et d'AI Movie Studio 2.

Stratégie (la même que Nexora WorkStudio) : partir d'une base open source mature (ici OpenField, MIT), l'enrichir de composants d'autres projets, et n'écrire que ce qui manque ou nous différencie. Licences d'origine conservées.
